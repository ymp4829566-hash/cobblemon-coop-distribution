# Cobblemon Coop Distribution

코블몬 협동 서버의 클라이언트 자동 업데이트 배포 저장소입니다.

- `manifest.json`: 간편 설치기가 확인하는 최신 버전 목록
- `files/`: 자체 제작 협동전·전설 제단·챕터 맵 JAR과 최신 간편 설치기
- 최신 설치기: [`cobblemon-coop-installer-alpha25.exe`](files/cobblemon-coop-installer-alpha25.exe)
- 공개 모드 의존성은 이 저장소에서 재배포하지 않고 공식 Modrinth CDN에서 받습니다.

이 저장소에는 계정 토큰, 서버 비밀번호, 비공개 소스 코드를 올리지 않습니다.
